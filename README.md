# 🚀 Portafolio de Automatización con n8n

Portafolio práctico de proyectos de automatización orientados a resolver procesos reales mediante n8n, APIs, Webhooks, Inteligencia Artificial, arquitectura orientada a eventos e integración de diferentes servicios.

Los proyectos demuestran la capacidad de construir flujos que reciben información, procesan datos, toman decisiones, gestionan excepciones en producción y ejecutan acciones automáticamente.

---

## 👨‍💻 Sobre el portafolio

Este repositorio reúne soluciones de automatización desarrolladas para optimizar flujos de trabajo en entornos operativos y de desarrollo.

Mi objetivo es diseñar arquitecturas de automatización resilientes y escalables que permitan reducir tareas manuales, conectar diferentes herramientas, garantizar la continuidad del servicio e integrar inteligencia artificial en procesos de negocio.

## 🧠 Habilidades demostradas

- 🚨 **Resiliencia y Observabilidad:** Captura global de excepciones, arquitectura de *Error Workflows* desacoplados y monitoreo en tiempo real para reducción del MTTR.
- 🔗 **Integración y consumo de APIs REST:** Conexiones HTTP, autenticación por Token/OAuth, y manejo de webhooks en entornos de test y producción.
- 🤖 **Inteligencia Artificial / LLMs:** Integración de modelos de lenguaje (Groq, OpenAI) con *prompt engineering* y extracción de respuestas estructuradas en JSON.
- 🐳 **Despliegue y Contenerización:** Configuración y ejecución de entornos de automatización con Docker.
- 🔄 **Automatización End-to-End:** Diseño de flujos orientados a la continuidad del negocio y enrutamiento dinámico de datos.
- 📊 **Transformación y Limpieza de Datos:** Expresiones en JavaScript, normalización de payloads JSON y manejo seguro de variables (`Optional Chaining`).
- 📦 **Manejo de colecciones de datos:** Procesamiento en lote, agregación y filtrado condicional de arreglos (`Filter`, `Aggregate`).
- 🔀 **Lógica de negocio:** Implementación de nodos condicionales y de control de flujo (`If`, `Switch`, `Edit Fields`).
- 💬 **Sistemas de notificación y mensajería:** Notificaciones automatizadas y alertas técnicas vía Telegram Bot API (Markdown) y Gmail API.
- 📋 **Persistencia de Datos:** Lectura, escritura e historización en hojas de cálculo y bases de datos (`Google Sheets`).

## 🛠️ Tecnologías

- **Plataforma:** n8n, Docker
- **APIs & Webhooks:** REST APIs, HTTP Request, Telegram Bot API, Gmail API, Google Sheets API
- **Inteligencia Artificial:** Groq API, OpenAI API
- **Arquitectura & Resiliencia:** Error Triggering, Observability, JSON Parsing
- **Lógicas & Lenguajes:** JavaScript (Expressions), JSON, Markdown
